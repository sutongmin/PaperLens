# 📚 PaperLens —— 论文速读与关键词提取助手

**PaperLens** 是一个基于 HTML、CSS 和 JavaScript 开发的轻量级论文辅助阅读工具，旨在帮助用户快速了解论文内容、提取关键词，并估算论文阅读时间，提高文献阅读效率。

## ✨ 项目简介

在日常学习和科研过程中，阅读大量学术论文往往需要花费较多时间。PaperLens 希望通过简单直观的网页界面，为用户提供便捷的论文内容分析功能。

用户只需将论文摘要或正文粘贴到输入框中，点击分析按钮，即可获取相关分析结果。

## 🚀 核心功能

- **关键词提取**：从输入的论文文本中提取关键词，帮助用户快速了解论文涉及的主要内容。
- **论文内容概览**：展示论文内容摘要式概览，帮助用户初步掌握文本主题。
- **阅读时间估算**：根据输入文本长度估算阅读所需时间。
- **中英文文本支持**：支持输入中文和英文论文内容。
- **历史记录管理**：保存历史分析记录，方便用户查看之前的分析结果。
- **简洁直观的界面**：采用简洁的网页布局，降低使用门槛。

## 🛠️ 技术栈

| 技术 | 用途 |
|---|---|
| HTML5 | 构建网页结构 |

## 💻 运行方式

本项目是一个纯前端轻量级项目，无需安装复杂的开发环境，也不需要配置数据库。

1. 下载或克隆本项目：

   ```bash
   git clone https://github.com/你的GitHub用户名/PaperLens.git
   ```

2. 进入项目文件夹。

3. 使用 VS Code 打开项目。

4. 找到 `index.html` 文件，使用浏览器打开即可。

也可以在 VS Code 中安装 Live Server 插件，通过 Live Server 启动项目。

## 📖 使用说明

1. 打开 PaperLens 网页。
2. 在论文内容输入框中粘贴论文摘要或正文。
3. 点击「开始分析」按钮。
4. 查看关键词提取结果。
5. 查看论文内容概览。
6. 查看预计阅读时间。
7. 在历史记录区域查看之前的分析记录。
